# Decode-labs-Project 1
A simple command-line To-Do List application built with Python. It allows users to add, view, and delete tasks using task IDs, making task management simple and organized.
## Features
- Add new tasks with unique IDs
- Prevent duplicate task IDs
- View all tasks in a clean list format
- Delete tasks by ID
- Simple menu-driven interface
- Screen clearing for better UX
## Technologies Used
- Python
- Git & GitHub

## How to run 
- Clone the repository
- Open the terminal
- Run:
```bash
python Project1_Decodelabs.py
```
